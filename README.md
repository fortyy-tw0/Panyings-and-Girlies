# Panyings-and-Girlies

Your cycle. Your device. Your data.

A private menstrual-cycle tracker and AI companion that works locally on the user’s device.
Users can:
- Record period dates and symptoms
- Receive cycle predictions
- Understand personal patterns
- Ask menstrual-health questions
- Journal, complain, or rant freely
- Use the important features without internet
- Keep reproductive-health information on the device

Main features

1. Period and cycle tracking

Users can record:
- Start and end dates
- Flow level
- Pain or cramps
- Mood
- Energy
- Sleep
- Headaches
- Bloating
- Discharge
- Skin changes
- Medication notes
- Custom symptoms
- Private written notes

The user should decide which categories appear. They should not be forced to answer everything.

---

2. Cycle predictions

SikLo can provide the familiar prediction categories found in period-tracking apps:
- Estimated next period
- Expected period window
- Expected period duration
- Average or median cycle length
- Recent cycle-length range
- Symptom patterns
- Changes over time
- Prediction confidence
